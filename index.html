ML-Based Adaptive Load Balancer Oct 2026

Layer-7 HTTP load balancer built from scratch on raw asyncio TCP sockets (no nginx, no proxy libraries). Parses HTTP by hand, handles timeouts, retries and active health checks, and supports round-robin, least-connections and an ML strategy that routes each request by predicted latency (gradient boosting, epsilon-greedy exploration, automatic fallback).

  • Burst load: p95 latency 737 ms (round-robin) → 607 ms (least-connections) → 145 ms (ML).
  • When the fastest backend slowed down mid-test, ML cut its traffic share from 70% to 7%.
